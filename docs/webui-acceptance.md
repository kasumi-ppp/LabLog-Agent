## 双轴本地审查与修复

Standards 轴和 Spec 轴分别只读审查工作树。已修复：

- 后台采集窗口发生人工保存时，在共享文件锁内再次检查 `manual_saved`，保留原文件字节。
- 真实模板已配置时，首次人工编辑不能只停留在 SQLite；需写入自动任务读取的同一 JSON。
- 清空进展/问题/措施时清空模板总结字段，避免发送预览中已删除的文字。
- 日期请求失败保持原日期与正文绑定；加载期间禁用编辑。
- 完整同步移除本期退出授权证据快照的自动候选，保留人工项并尊重 `retention=retain`；原始证据读取检查当前范围。
- 拦截跨站写入及无令牌时的非本地主机名；远程 API 需访问令牌。
