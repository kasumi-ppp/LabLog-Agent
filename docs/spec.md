# LabLog-Agent 开发约束

用户授权从零创建 GitHub 仓库 kasumi-ppp/LabLog-Agent。主要来源是本机 Codex 工作会话，Git 与显式配置的 Markdown 为补充；支持指定项目/会话和自动发现。只采集报告日期范围内的实际消息，不读取思考过程、凭证或任意磁盘文件。事实必须带来源，计划不可当成完成，工时不可编造。

日报、周报、月报使用现有学生模板；固定目标为 iSyslab@Hust、胡喆、薛志东老师。个人身份与用户 ID 只写本地配置。首次指定原文逐字保留。禁止把原文当作当天完成的开发成果。

仅通过官方 DWS CLI 操作钉钉。模板和字段以实时返回为准，字段按 sort 排序。数字、日期、附件不能假装普通文字。未知非文本编码必须阻止提交，不猜测。preview 和 dry-run 不得写入远端。用户确认具体草稿的 hash 才可提交；需核验身份、收件人、模板、重复记录，写入提交中状态后调用。超时/结果不明不得自动重试。成功必须读取详情逐字段验证。保存 JSON 状态、原子更新、跨进程锁。

首次不启用定时任务。Windows 任务计划支持每日/每周/每月生成；全自动提交需要另行明确授权范围。节假日/调休按有来源的年度配置；缺少年份时停止定时任务而不是默认为周一至周五。

所有原始证据、真实报告、日志、本地配置均留在 Git 忽略的 data/ 等目录。对已实现/已测试/未做实测/受阻功能明确区分，不把 dry-run 声称成真实提交。
